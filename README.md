# TKTPASJEGERE

Service d'assistance aux travaux pratiques avec interface 3D, import PDF, historique des demandes et générations multilingues.

## Langues

- Français
- English
- Lingála

## Développement

```bash
npm install
npm run dev
```

## Variables d'environnement

```env
OPENAI_API_KEY=
WHATSAPP_API_TOKEN=
WHATSAPP_PHONE_NUMBER_ID=
ADMIN_PASSWORD=
NEXT_PUBLIC_APP_URL=
```
